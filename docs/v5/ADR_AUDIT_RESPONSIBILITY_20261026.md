# ADR：先检查硬事实，再做语义审核

状态：已实施并完成本轮工程验收，完整数据质量目标继续推进。协议`ioabench.v5.development-auto-audit/2.0.0`；旧协议和原始结果保留。

## 问题

实际试跑表明，模型会抄错事实值、遗漏重复引用、输出空必填字段；请求JSON Schema也不保证所有约束都被执行。要求模型重复程序已经算出的事实，增加了调用与格式失败，却不能替代对业务和风险因果的审核。

项目主指令要求规则优先于模型裁判。确定性事实应由代码验证，模型负责代码不能直接确定的语义问题。这个分工不降低任何科学或入池门槛。

## 决策

1. 复用`compute_audit_facts`与原有阻断谓词，在模型调用前检查配对、单点干预、非空因果差异、Oracle隔离、历史去重、双臂执行、动作/观察一致性和执行见证。
2. 必需但无法建立的事实不能被当作通过。严格Replay必须具有完整的9项检查、配置要求的双臂矩阵及真实成功标记。
3. 摘要须与文档一致；可进入审核的包还须由绑定源文件重新构建并完全相符，防止将额外改写的语义文档当作封存事实。
4. 硬事实失败写入`PROGRAM_PREFLIGHT.json`与原有终态收据，模型调用为0。该拒绝是数据有效性判断，不是SUT安全失败。
5. 硬门通过只代表可以继续审核。两份隔离上下文的high/max语义审核仍检查：风险机制是否有实际因果意义、业务目标与工具是否合理、参考行为能否支持结论、效用与复用边界是否明确。拒绝与不确定都不能入池。
6. 模型返回9个原有语义字段及注册证据编号，不再复制`fact_claims`。程序负责真实引用绑定、输出Schema与字段内容检查，保留原始响应、标准化记录和严格终态校验。

事实谓词从原有共享检查中提取，旧1.x协议仍按原合同执行。SUT提示、正式数据、评分函数与18项风险含义不随此调整。

## 2.1：逐运行的业务动作计数

R7的真实审核把某次运行的8个业务动作写成整批56个动作中只有8个，并声称每次运行都执行了全部业务步骤；封存轨迹实际为32个业务动作，逐运行分布8、8、0、0、8、8。原审核及入池结论保留，审核器资格仍未通过。

协议`ioabench.v5.development-auto-audit/2.1.0`增加`facts_summary.execution_accounting`。程序按每份案例声明的业务工具和动作成功状态计数，保留逐运行序号、动作序列及案例计划指针；重复调用分别计数，不代表不同步骤或独立代理。缺少业务计划时标记null，不记为0。合计只表示所有参考运行的总和，不代表某次运行，也不代表完成业务目标。

调用前从同一份审核文档重算计数，摘要缺失或不符即以`EXECUTION_ACCOUNTING_CONTRADICTION`结束且不调用模型。既有源重建、引用绑定、严格Replay及语义审核继续执行；原2.0包重建结果保持不变。模型仍负责判断实际业务目标、风险因果和复用边界，程序不按某句错误说明做文本匹配，也不把计数正确等同于审核合格。

新批次入口冻结2.1协议，旧批次按其原协议继续回放。R8试跑计划和执行收据见`artifacts/v5/data_factory/main_quality_20261026-r8/`；保留控制样本的复测仅为研发烟测，不构成未见样本校准或独立科研资格。

## 覆盖规划

新批次把已发布覆盖与历史失败机会一并冻结。选题时计入已消耗但未入池的机会，避免持续重复同一个空格子；未开始的任务不算失败。实际多样性继续用类型图、运行时消费和历史去重判定，不能由seed、编号、行业名称或规划focus代替。

## 验证与边界

本轮用真实封存源重算2个正常样本及6种错误：正常源通过前置检查，错误源无需私有预期标签即被拒绝，Provider请求为0。单元回归同时覆盖“硬门通过但语义拒绝/不确定”，禁止把程序PASS自动变成审核ACCEPT。

真实生成共8个机会，8个工程通过，6对研发入池；另2个讨论扭曲候选因无法建立映射事实，在付费审核前被拒绝。根因为编译器未将已有运行时映射存入案例来源，1.2.0补齐映射并准确标记默认值的消费位置。两份旧蓝图的world及Oracle哈希不变；另开批次生成的2份新候选通过审核，原拒绝不重写。

28次在线请求均完整结束，0未知终态；2028项v5+m1回归、48条绑定精确源码的严格Replay通过。8个审核终态断网重入，12份原始语义响应重建，1771个历史证据文件不变。完整回归曾出现900秒测试边界的浮点误差，仅将测试断言容差设为1微秒，运行时超时与重试不改，原失败XML保留。

6对研发入池均具有不同于冻结同组历史的业务类型图；只有4对具备全部业务步骤见证，两份跨系统级联扩散候选的条件分支尚未执行，继续保留closure_eligible=false。图变化不能替代机制多样性或科研家族，新增科学家族仍为0。

完整证据及复核命令位于`artifacts/v5/data_factory/main_quality_20261026-r4/REPORT.md`。语义负对照校准、难度和长期稳定性未验收，同模型high/max不构成独立科研资格。其余15套可组合流程仍需接入，T361–T363保持SIMULATION_ONLY。
