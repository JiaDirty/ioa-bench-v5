**R3-P0** T321 至少三段实际执行、业务见证关联准确、真正可组合 DAG；**R3-P1** 同一通用编译路径在 T331/T362 可用，并验证未预置的拓扑；**R3-P2** 冻结对照、质量/多样性/失败分母、最终交接。不要反复重写已存在的 R2 状态机、AIHubMix client 或安全门。

`行业模块目录 → 模型提出 WorkflowPlan(DAG) → Typed MechanismIR(来源约束) → CapabilityPlanner/Compiler → [CONTROL,RISK] → 确定性执行 → WitnessVerifier → 原有硬门 + strict Replay + 历史去重 → 双模型档研发审核 → DEV_ACCEPTED`。
