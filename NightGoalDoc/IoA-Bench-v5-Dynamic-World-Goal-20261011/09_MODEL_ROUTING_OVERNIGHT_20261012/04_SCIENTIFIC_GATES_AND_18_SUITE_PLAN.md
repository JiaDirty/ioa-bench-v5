# 18 Suite 科研不变量与阶段验收

## 18 Suite 全范围
T311 T312 T313 / T321 T322 T323 / T331 T332 T333 / T341 T342 T343 / T351 T352 T353 / T361 T362 T363。
T361–T363 始终保持 `SIMULATION_ONLY`，不得宣称真实人类验证。

## 各阶段可验收产物
1. **世界/Runner**：已知 18 Suite 对照/风险行能够通过正式动态入口，Agent 自主选择合法工具，事件与状态因果完整，监测失败时不假装有效；T321/T331/T352 给出不依赖 witness 的多路径真运行证据。
2. **数据工厂**：实测多种主流模型路由/回退，能够把符合 Schema 的蓝图转为真的 task/evidence/authorization graph；编译 `CAPABILITY_GAP` fail-closed；按真实执行结构判定新家族，跨 run 索引拒绝伪新颖性；独立审查有稳定机器可读格式和严格负例。
3. **跨构念复制**：至少先在 T321、T312、T331、T352 的不同测量机制下通过同一数据生产与运行接口的端到端契约；再按 Suite 簇推进全部18项。不能把18个手写固定模板当成18套成熟 AI 生成器。
4. **候选数据**：18 Suite 各独立候选池，CONTROL/RISK 同源配对，预注册风险操作/参考策略/GT/Oracle/评分语义不变；记录真实质量拒收、结构家族、证据暴露、执行效用、token/错误、覆盖缺口。数字配额以现有已批准协议为准，不凭空提高样本目标。
5. **预审与人审准备**：自动化盲包、标注指南、独立审阅提交入口、仲裁计划、评分一致性检查、各项 evidence index；无需人类时完成所有自动可复验前置步骤。
6. **正式测量**：只有经批准 Gate、明确冻结模型身份/协议/样本及单独授权后执行确认 Pilot 和 Campaign；不得用生成模型或审核模型替代正式被测协议，也不得根据危险率挑样本。

## 禁止的捷径
- 降质量阈值换取样本数；把行业换皮算成新结构；只依赖审核模型 PASS 而缺本地确定性 Gate；不记录审核独立性；更换不稳定模型却不记录 resolved id；未观察到的推理内部状态当作测量事件；自动将人类 Gate D 标为通过；无批准冻结正式测评。

## 无法满足条件时的正确交付
返回 `PARTIAL` 或 `BLOCKED`，附根因、剩余真实障碍、可证伪的下一步、源码/测试/证据位置；允许交付生产前候选与自动生成链，但不能宣称 SCIENTIFICALLY_READY。
