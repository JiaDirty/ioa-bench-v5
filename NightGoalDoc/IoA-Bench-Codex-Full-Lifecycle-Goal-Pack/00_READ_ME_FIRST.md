# IoA-Bench Full-Lifecycle Codex Goal Pack

这个包替代此前“只完成构念代码阶段”的夜间 Goal。

本次 Goal 覆盖整个项目剩余生命周期：

1. 18 项 construct-valid code + 开发期离线测试；
2. 18 项完成后，逐 suite 试生成数据；
3. 调通每 suite 生成 recipe；
4. 批量生成与冻结正式 Dataset；
5. 小规模 AIHubMix online pilot；
6. 单 suite 正式在线测评；
7. 依次完成全部 18 项；
8. 聚合报告、Dashboard、复现包；
9. Final Scientific Acceptance；
10. Project complete。

核心策略：

**代码先全部实现；数据和在线后逐 suite 做。**
**数据先试生成，验证生成方法正确以后再批量。**
