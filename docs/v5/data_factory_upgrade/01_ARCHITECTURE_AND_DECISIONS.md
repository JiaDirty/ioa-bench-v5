# 数据工厂增量实现决策

本轮复用现有 `GeneratedSuiteAdapter`、`pipeline.suite_spec`、`compile_and_gate`、动态 runner、参考策略、quality、FamilyRegistry 和 AIHubMix ModelPort。18 项套件现均有类型化入口：T312/T321/T331/T352 使用专用编译器，其余 14 项共用 `BoundedWorldCompiler 1.0.0`。19 个动态 slice 仍分别注册；T321 的额外 DYNB 执行结构不因此获得独立 typed compiler。精确字段、版本和消费者见 [18项能力矩阵](02_SUITE_CAPABILITY_MATRIX.md)。

约束树只组合已实现的有限原语：证据的投递/查询方式、权限投影、任务释放依赖、已列出的拓扑和反馈治理。它不接收任意任务图、新工具、新权限体系、新真值或新评分。T321 的 `task_graph` 与 `evidence_plan` 是经能力检查的路径/载体元数据，依赖声明不会自动变成运行前置条件。未知字段、不可行组合或缺少消费者证明的提案明示拒收，不能压成文案后声称结构支持。

三项样板已有实际消费者。T321 在 2/3 Broker、初始/gamma 后资料发布之外增加 `offer_access=scheduled_push/broker_query`：查询模式先发布来源绑定的目录通知，之后由 `read_offer` 读取相应已发布报价。T331 支持 `fanout/chain/fork_join`，其中 fork/join 仅允许宽度 3，实际执行 `a→b1,b2; b1→b3; b2→b3`，并检查汇合角色的真实输入。T352 将 `broadcast/local_receipt_query` 与 `published_static/shared_rating_aggregate` 组合，后者把实际提交的评分聚合、发布并交给后续 `read_history` 消费。人数、组织名、业务标签和叙述变化本身不构成新家族。

其余 14 项已经实现闭合的二值证据/释放原语，不能继续标为“只有叙事扩写”。例如 T311 的凭证文档须实际投递后才有引用可查，T323 的异步重建须在请求轮次之后安装并回复，T342 的登记簿查询由真实角色工具权限约束，T361 的批次释放须让模拟 reviewer 实际处理每项。默认分支兼容原消费者；新增分支必须有可见消息、工具回执、来源、时序和后续实际 `ModelRequest` 的证明。

CONTROL/RISK 使用相同的非风险原语，差分仍由套件的机制槽和细粒度 arm-delta 检查约束。Ground Truth 由程序世界构造；辅助 AI 不获得改写 Oracle 或评分的权限。参考策略用于检验可行机会和消费者保真，合法替代安全路径也要通过；不会把 witness 的固定动作序列变成 SUT 的强制安全答案。T363 场景/生成器 0.5.0 修正了 S2–S5 的第二阶段两臂设置相同问题；该修正生成新版本，旧 H 难度拒收证据保留，不能套用旧清单的通过状态。

`execution_fidelity` 由真实 pair Gate 调用，检查实际执行而非计划字段。缺通知、错来源、漏投递、错误权限、提前返回、实际工具回执缺失，以及“业务仍完成但结构消费者断开”的负例均应拒收。此检查决定候选编译/运行是否可信，不改变已批准的模型评分。构念、正式被测 DeepSeek 配置、经典套件与已批准评分语义不因辅助结构迁移而变更；场景版本、编译器版本及真实调用配置分别记录。T361–T363 始终为 `SIMULATION_ONLY`。

保留旧 CoveragePlanner.plan 与工厂 offline/live 参数；新计划、历史索引、预检、审核控制和校准入口调用同一套编译、执行与 provider 代码。历史索引接纳已拒收结构作参考，保留其原资格，不把“见过”当“通过”。静态结构差异只能是结构候选，必须有真实行为证据才升级。

独审增加可检查的事实断言：引用路径必须存在，且断言值与实际叶子值一致。它验证引用的事实支持，不能证明整段语义推理；审核准确性和重复一致性仍需固定正、负、弃权控制集的实际结果。审核 FAIL/ABSTAIN、缺少证据和模型渠道失败分别保留，不能靠换裁判重投获得 PASS。

Provider 分类恢复仅针对渠道故障。401/403 阻断该凭据；未知是否成功的请求保持 REQUEST_UNRESOLVED；替补调用使用新 attempt/subrun，保留原记录。模型输出质量差、结构重复、审核 FAIL/ABSTAIN 都保留拒收，不靠重投裁判取得 PASS。

分层开发池复用现有 family/source 身份和证据绑定，分别记录结构通过、机器资格、经验实测与科学/正式冻结；层级不可因文件存在或标签出现而自动晋升。development、judge-control、calibration、pilot、final-hidden 的同家族或共享来源冲突必须显式报告。冻结 manifest 和引用证据不可变，续跑产生可追溯的新证据，不覆盖历史记录。

验收以机器产物及其源哈希为准。当前 `capability-manifest-20261019-r5` 记录18个typed注册/支持项、19个slice、540个真实本地参考episode；runtime为 `4f7fc7c842ea63a352157baffe8252838fdc06332e2839fd3ddb6f250e04e9e5`，含T363 0.5.0和T352 0.4.0。R13完整回归1486 passed，覆盖r8实际132对/264例/828参考检查，另有72回合严格参考Replay及无新增调用恢复。有限语法有49个规范可行结构，覆盖选中44个；不等于全历史新家族或线上机器资格。脚本策略、真实模型实测、独审资格及各层池证据分别报告，不能互相替代；最终集成结果见04文档及机器交付。

真实恢复/池试跑又发现三处序列化边界缺陷，均先复现后补回归：历史同case的相同行为探针仅执行结果哈希不同，合并保留旧探针并绑定新来源，真正行为/身份/policy差异仍拒绝；校准合同1.2.0按规范JSON比较list/tuple，完成/停止终态先验证全部绑定证据，再于Provider和密钥读取之前只读返回；开发池1.0.2按规范JSON比对重新编译的pair，T341/T343的chain元组落盘为列表不再误拒，真实叶值变化仍拒绝。旧失败和原合同不升级重标。R12的 `bde196…` 到R13只改runtime的pool.py，完整426文件、静态与隔离实际导入闭包桥接见 `POOL_SOURCE_DEPENDENCY_BRIDGE_R13.json`；当前确定性链仍实际重跑。剩余在线面板以独立source amendment绑定新source，原样本、模型和参数未按行为调整。

未执行项写 `NOT_RUN`，未核实模型身份/能力写 `UNVERIFIED`，E/M/H 设计标签与在线经验难度分开。结构多样性、机器审核、工程完整性、科学有效性和正式冻结分别判定；当前这些辅助工程证据不授予确认性 Pilot、正式 Campaign、真人实验或科学冻结资格。
