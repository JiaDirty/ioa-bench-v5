# 给网页端 ChatGPT 的项目审阅说明

本包是 2026-10-10 整理后的 IoA-Bench 工作区源码审阅快照。审阅主线为 v5，历史源码、规范和状态记录也保留在源码目录中。它不是正式发布包，也不是完整历史运行回放包。

## 先读这些文件

1. `docs/v5/PROJECT_PROGRESS_18_SUITES_20261010.md`：18 项测评的实现、接口、版本和剩余问题。
2. `AGENTS.md`：研究目标和不能改变的科学边界。
3. `docs/v5/V5_00_ARCHITECTURE_DECISION.md` 与 `contracts/v5/construct_maps.json`：v5 对每项风险的具体定义及因果设计。
4. `docs/v5/V5_PROGRESS.md` 与 `docs/v5/V5_PI_DECISION_LOG.md`：当前进度和已记录决策。
5. `src/ioabench/v5/core/`、`src/ioabench/v5/suites/`、`tests/v5/`、`scripts/v5/`：当前实现和验证工具。
6. `artifacts/v5/pilot/pilot-20261006-v5.1.5/deepseek_single_model_diagnostic.md`：历史在线试点逐项诊断。

## 已知状态

- 测评对象是模型在受控智能体互联场景中的可观察安全行为。环境服务、攻击者脚本和合成人物是实验刺激，不是被评安全产品。
- v5 的 18 项模块、生成器、场景、评分器和参考策略已实现。2026-10-10 实际执行结果：v5 测试 71 passed；离线矩阵 3,240/3,240 通过。脚本策略的离线通过不能证明在线模型表现或科学有效性。
- `5.1.5-candidate-20261006` 每项有 60 对对照/风险案例，共 2,160 案例；未冻结。包内另保留结构暴露的 `5.1.6-candidate-20261009` 局部修复数据，不把它当成全部 18 项的新版本。
- v4.1.13 的历史正式运行曾完成，但后续科学审计记录为 `NOT_SCIENTIFICALLY_READY`。`state/PROJECT_STATE.yaml` 顶部有历史完成字段；当前 v5 状态在其 `v5` 节，不要把两者混为一谈。
- 独立验证 Gate D 没有实际人工/专家评审标签。历史四模型试点因模型身份不一致等原因未通过 Gate E；216 条 DeepSeek 历史诊断也不能替代新的确认试点。
- 正式模型已选择 `deepseek-v4.1-flash`；历史响应元数据为 `deepseek-v4-1-flash-260910`。新的付费确认试点和正式运行尚需各自的批准与前置验收。本次整理和打包没有调用 Provider。
- 判断让渡、讨论扭曲、能动性弱化仅为 `SIMULATION_ONLY`，不能直接声称测量真实人的能动性。

## 包含和缺省范围

包含当前 `src`、`tests`、`scripts`、配置、协议约束、场景、世界定义、角色、提示词、模板、文档、ADR、目标文档和项目状态；包括当前 v5 候选数据、最新离线结果、数据质量摘要、试点诊断、科学审计摘要和根目录 Release JSON 元数据。

不包含真实 `.env`、凭据容器、缓存、虚拟环境、旧 ZIP、导出历史、候选源码备份和完整在线轨迹。包内 `_snapshot/FILES.json` 是实际文件清单，`EXCLUDED.json` 是缺省清单，`SNAPSHOT.json` 说明证据边界。未包含的路径不能凭目录引用推定其内容已被审阅。历史 Release 的冻结源码和完整回放也未包含，不能只凭此包重新验收历史运行。

候选数据含程序真值，供审阅生成和评分逻辑使用，不可把它传入被测模型。独立盲评包的 sealed key 未作为本包审阅材料纳入。

打包完成记录保存在压缩包外的 `PACKAGE_VERIFICATION.json`；包内项目状态是开始打包时的快照，打包任务本身可能显示 `in_progress`，不影响上述研究状态。
