# Direct DeepSeek engineering call contract (2026-10-13)

Scope: temporary, source-pinned engineering tests with the user's direct DeepSeek API. This does not freeze a formal dataset or replace the registered AIHubMix `deepseek-v4.1-flash` tested-model configuration.

Official local snapshot: `D:/Project/Playground/scrape/deepseek-docs/md/en/` (`index.md`, `api/create-chat-completion.md`, `api/list-models.md`, `guides/thinking_mode.md`, `guides/tool_calls.md`), fetched 2026-10-13. The exact document hashes for the first online check are in `artifacts/v5/evaluations/direct-deepseek-flash-20261013-official-t311-r1/CONFIG_VERIFICATION.json`.

The direct path uses `https://api.deepseek.com/chat/completions` and resolves `deepseek-flash` through the live `/models` catalog before an engineering batch. The request explicitly sets `thinking={"type":"enabled"}`, `reasoning_effort="high"`, `stream=false`, and `max_tokens=131072`. Thinking mode ignores `temperature`; it is omitted. The API documents a maximum of 393216 output tokens; the lower engineering ceiling is a recorded run parameter, not a statement about model capability. The API key is read from `DEEPSEEK_API_KEY` in the process environment and is never written to the run manifest or report.

For each tested agent, the engine preserves the complete conversation in order. An assistant message retains `content`, `reasoning_content`, and any `tool_calls`; matching `tool_call_id` results follow it. All earlier assistant reasoning is returned with subsequent tool-carrying requests, as the official Thinking Mode tool-call guide requires. Different tested agents keep separate histories. The direct adapter parses the final text, tool calls, usage, response ID, served model, and finish reason into persisted response records. Reasoning is replayed for protocol fidelity and recorded for reconstruction; scoring continues to rely on observable text/actions and external ground truth, never on the reasoning text as a safe-action substitute.

The existing AIHubMix protocol remains unchanged. Direct requests use `ModelProfile.provider=deepseek`; the engine's new branch applies only to that provider. Engine version `v5-episode-engine-1.4.2` records this protocol change. The previous 8192-token run, its five truncated rows, and its pinned source were preserved; the source ZIP and hash manifest sit under `artifacts/v5/evaluations/direct-deepseek-flash-20261013-all-r1/`.
