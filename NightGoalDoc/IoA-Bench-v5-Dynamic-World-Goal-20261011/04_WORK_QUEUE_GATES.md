## 每阶段最少测试材料

- 可重放最小 fixture；主线/新世界对照的兼容测试；参数化/属性测试（不同动作次序、工具失败、重复调用、权限变更、并发、不变式）。
- CONTROL/RISK **非机制字段不变**的程序证明；对潜在混淆变化有明确错误而非被吞掉。
- 同一风险的正例、负例、难例、合理安全替代路径、拒绝导致效用失败、可恢复与不可恢复后果。
- 外部真值计算证据、模型不可见 evaluator 事实的防泄漏检查；所有已执行动作具有完整事件。
- 编译前后保真对照报告；世界能力不支持的字段逐项标 `CAPABILITY_GAP`；各 Gate 输出 hash 和版本。
- 数据多样性跨批/跨正式候选近邻比较，不靠行业替换；审核模型的错误拦截能力要用既知问题集证明。
- 只在关键共享运行语义发生改动时做完整18项/3240历史矩阵，普通局部改动优先针对性测试；不可省略受影响范围的回归。

## 原有科学 Gate A–H，不另造替代方案

- **A 构念与因果**：18项 construct maps、假设、控制变量、机制区分/消融和外部内容审查。
- **B 评分效度**：Safety/utility/recovery/abstain 分开，独立标注与计分器一致性，已知歧义敏感性。
- **C 数据质量**：family 独立性、拓扑/证据/行为路线/机制覆盖、去重、合法难度、无泄漏、可计算真值。
- **D 独立审阅**：真实盲审/领域专家及分歧处理；AI 复核不替代；没有评审者就 `BLOCKED_EXTERNAL_REVIEW`。
- **E 确认 Pilot**：真实被测模型且测试科学测量机制，而非故意追高失误率；门槛失败先修，不把 Smoke 当 E。
- **F 版本冻结**：代码、case哈希、Prompt、工具/路由/预算、模型真实身份、测量函数、抽样分母及统计方案全部 pin。
- **G 正式 Campaign**：仅在 A–F 合格、单独 PI 批准后执行，不对个别 bad case 选择性重试，不混用历史预算。
- **H 统计与科研交付**：计划分母/有效分母/无效与基础设施、配对失效/效用、聚类不确定性、消融、可支持及不支持主张。

## 不能用形式主义验收

禁止用以下单项替代完成：`18/18 Suite代码存在`、`JSON合法`、`check_pair全过`、`GLM PASS`、`模型工具调用顺利`、`跑完216个案例`、`测得不安全分数`、`测试全绿`。它们都是必要的局部证据，不是充足的科研结论。

所有里程碑状态标准化为 `NOT_STARTED / IN_PROGRESS / VALIDATED / BLOCKED / PI_DECISION_REQUIRED`；阻塞时明确可自主完成的工作、缺少的证据及解锁方式，不猜测完美完成。
